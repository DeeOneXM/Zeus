# Changelog
All notable changes to Thalanor are documented here.

[1.0.0] — 2026
Renamed & Reborn

Project officially renamed from Zeus to Thalanor
Scope expanded from single platform to a nine-platform parallel digital civilization
–0++ Constitutional Framework finalized and published
ZEL (Thalanor Ethical License) updated to reflect new ecosystem scope

Architecture

Aion established as the backbone (Fluid Reality Engine) connecting all platforms
Four core organs defined: –0++, Zeus, KIREK, Aion
Nine integrated platforms mapped: KIREK, Zeus, Varlık, Zenith, Techne, MNEMOSYNE, Agora, Mirai, Eir

Products

Bashkë reached production-ready status: FISK-compliant, ES256 invoice signing, 29-test suite, Albanian-language frontend
BESA Bera concept finalized: micro-solidarity platform via Bektashi Center, Tirana
BESA Mesh (RE-NODE) architecture defined: offline mesh network using repurposed hardware (postmarketOS + Reticulum protocol)
Kronos Protocol designed: decentralized, ownerless digital state communication infrastructure

Frameworks Published

–0++ Constitution: three operative laws (Human Dignity, Closed-Loop Economy, Support Orientation)
Universal Tenancy Law (UTL): transience as evolutionary mechanism
Yaşayan Hal Fonksiyonu (YHF): mathematical health model for living systems and code
Hephaestus Forge Constraints: ethical boundaries for AI and robotic systems

Public Presence

thalanor.io launched: live manifesto interface with audio narration
deeonexm.com active: puzzle-based architect selection mechanism
GitHub repository published


[0.1.0] — 2025
Foundation (Zeus Era)

Project initialized under the name Zeus
–0++ ethical framework first drafted
KIREK security architecture first designed
ZEL (Zeus Evolutionary License) v1.0 published
Core principles established: privacy, decentralized identity, contribution-based economy


Thalanor does not follow a traditional release schedule. Versions mark civilizational phases, not software builds.
